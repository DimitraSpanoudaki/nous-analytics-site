# Nous Analytics — site

React (Vite) site με blog σε αρχεία Markdown.

## Ανέβασμα στο Netlify

**Γρήγορα (χωρίς κώδικα):** στο Netlify, Sites → Add new site → Deploy manually, και σύρε μέσα τον φάκελο `dist` (από το αρχείο `nous-analytics-dist.zip` αφού το αποσυμπιέσεις).

**Με GitHub (προτείνεται, για να ανεβαίνουν αυτόματα οι αλλαγές):** ανέβασε αυτόν τον φάκελο σε repository, σύνδεσέ το στο Netlify. Οι ρυθμίσεις build υπάρχουν ήδη στο `netlify.toml`.

Μετά το πρώτο ανέβασμα:
1. Site configuration → Domain management: σύνδεσε το nousanalytics.gr.
2. Forms: έλεγξε ότι εμφανίζονται οι φόρμες `contact` και `newsletter`. Εκεί θα βλέπεις τα αιτήματα. Στο Forms → Form notifications πρόσθεσε email για να ειδοποιείσαι.
3. Στείλε μια δοκιμαστική φόρμα για να βεβαιωθείς ότι έφτασε.

## Πώς προσθέτεις νέο άρθρο

1. Στον φάκελο `src/content/articles` αντίγραψε ένα υπάρχον αρχείο και δώσε του νέο όνομα με λατινικούς χαρακτήρες και παύλες, π.χ. `neo-arthro.md`. Το όνομα γίνεται η διεύθυνση του άρθρου (`/blog/neo-arthro`).
2. Άλλαξε την κεφαλίδα στην κορυφή:
   ```
   ---
   title: Ο τίτλος του άρθρου
   category: Αριθμοδείκτες
   date: 2026-07-15
   minutes: 5
   summary: Δυο προτάσεις που φαίνονται στην κάρτα.
   ---
   ```
3. Κάτω από την κεφαλίδα γράψε το κείμενο. Επικεφαλίδες με `## Τίτλος`, λίστες με `-`, έντονα με `**κείμενο**`.
4. Ανέβασε ξανά το site. Οι νέες κατηγορίες εμφανίζονται μόνες τους στα φίλτρα του blog.

Για να αλλάξεις ή να σβήσεις άρθρο, επεξεργάσου ή σβήσε το αντίστοιχο αρχείο.

## Άλλες αλλαγές

- Κείμενα αρχικής: `src/pages/Home.jsx`
- Πολιτική απορρήτου: `src/content/privacy.md`
- Χρώματα: στην αρχή του `src/styles.css`
- Εικόνα banner: `public/hero.jpg`

## Τοπικά

```
npm install
npm run dev
```
